# Public-facing status

RhymeLab is being prepared for a clean source-available public release. The public repository will start from a sanitized parentless root commit; the pre-public development repository, historical branches, commit metadata, and historical pull requests are intentionally not part of the public project history.

The current formally accepted German runtime baseline remains v0.10.0. Runtime source contains the validated hybrid-v3 ranking promotion for normal `type=all` ranked mode; final owner-local post-promotion acceptance remains pending.

See `PROJECT_STATE.json`, `docs/HANDOVER.md`, and `PUBLIC_RELEASE.md` for the current execution boundary.
